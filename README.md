This is the Github repo for the work arxiv: 2606.25600, `Two-dimensional Hyperbolic RNN Neural Quantum State'. (https://arxiv.org/abs/2606.25600)

- `utility_tfim`: contains the Python codes for the constructions of the hyperbolic NQS (both one-dimensional and two-dimensional) to be used in the 2D TFIM. 

- `1D_NQS`: contains the trained weights and inference notebooks for 1D Euclidean RNN/GRU NQS, Poincare RNN/GRU NQS and Lorentz RNN/GRU NQS (3 lattice sizes: (8,8), (10,10), (12,12)).
  
- `2D_NQS`: contains the trained weights and inference notebooks for Euclidean 2DRNN NQS and Lorentz 2DRNN NQS (3 lattice sizes: (8,8), (10,10), (12,12)).
